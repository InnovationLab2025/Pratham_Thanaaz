🌦️ Weather Dashboard

A responsive Weather Dashboard web application that allows users to search for current weather conditions and a 5-day forecast for any city worldwide.
Built using HTML5, CSS3, and JavaScript, it integrates with the OpenWeatherMap API to fetch real-time weather data.

🧩 Features

🔍 Search by City: Enter any city name to view its weather details.

☀️ Current Weather: Displays temperature, humidity, wind speed, and weather description.

📅 5-Day Forecast: Shows upcoming weather trends with icons and daily temperatures.

⚡ Dynamic Weather Icons: Automatically updates icons based on live weather conditions.

📱 Responsive Design: Works smoothly on desktops, tablets, and mobile devices.

🚫 Error Handling: Gracefully handles invalid city names and network issues.

 ⚙️ Technologies Used

HTML5 – Semantic structure

CSS3 – Styling, grid layout, and responsiveness

JavaScript (ES6) – Fetch API and DOM manipulation

OpenWeatherMap API – Real-time weather data

🧠 How It Works

User enters a city name in the search box.

JavaScript fetches data from the OpenWeatherMap API.

The current weather and 5-day forecast are displayed dynamically.

Errors (like invalid cities) are shown using an alert message.

🎨 UI Highlights

Modern card-based layout for better readability.

Animated SVG icons for weather conditions (sun, cloud, rain).

Clean color gradients and smooth transitions.
