🌸 LumiNest – Skincare Product Catalog
“Glow from the Inside Out” ✨

LumiNest is a modern, pastel-themed skincare product catalog built using HTML, CSS, and JavaScript.
It allows users to browse products, filter by category and price, add items to a cart, and view totals with tax applied.
Cart items can also be removed with a single click.

🌿 Features
✅ Product Listing

Displays products in a clean, responsive grid layout

Each product includes:

Image (locally stored)

Name

Price

“Add to Cart” button

🔍 Filtering System

Filter by category
(Cleanser, Serum, Moisturizer, Mask)

Filter by price range
(Below ₹500, ₹500–₹1000, Above ₹1000)

🛒 Shopping Cart

Add products to cart

Remove products from cart

Cart slides from right (overlay style)

Live total price calculation

12% GST tax auto-applied

Cart item count updates instantly

🎨 Aesthetic UI

Pastel color palette perfect for skincare brands

Modern floating UI elements

Attractive icons (using Font Awesome)

App branding:

Name: LumiNest

Tagline: “Glow from the Inside Out”

💾 Local Storage (Optional)

You can enable it to store cart data permanently
(default version uses runtime memory only)

🖼️ Adding Your Own Images

Place all product images inside:

/images


Then reference them in index.html:

<img src="images/image1.jpeg" alt="Cleanser" />


Make sure file names match exactly.
